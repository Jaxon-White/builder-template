# Sprint 3 Plan

**Goal:** The app has real Utah County resources in it instead of only sample data, and real
users (the professor, a bishop, and a DI worker) have used it and given feedback.

**Why this:** Testing the UX is the only thing I can do until I get access to the database,
and feedback from real users will be much better than my own opinion. I also want to get some
real data in so we can start using the app, even if it isn't 100% sustainable yet.

**Done looks like:** At least 10 new, real places are in the live app for others to use. I
have feedback on the user experience from at least 3 people: one bishop, the professor, and
one DI worker. My notes from each are in the repo.

**Predicted difficulty:** 2
